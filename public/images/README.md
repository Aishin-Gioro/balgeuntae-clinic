# 이미지 자산

파일을 이 폴더(`public/images/`)에 넣으면 자동 적용됩니다. 없으면 임시 배경(그라데이션/네이비)이 표시됩니다.
(문구·경로는 `lib/site.ts` 에서 관리)

> **최적화**: 원본 PNG/JPG는 `image-src/`(repo 루트, gitignore)에 보관.
> `image-src/`에 새 원본을 넣고 `npm run optimize:images` 실행 → `public/images/*.webp` 로 변환(가로 최대 1920px, q80).
